Entry Logic (Python Implementation)

if strategy_mode == "momentum":   if rsi_prev < target_rsi and current_rsi >= target_rsi:     if current_close > current_sma50:       passed_rules = True       rank_score = current_close / high_52w

Ranking Mechanism

RankScore = Current_Close / 52_Week_High

Stocks trading closest to their 52-week highs are prioritized. This identifies the strongest momentum candidates that are breaking out or maintaining leadership positions.

Data Flow Architecture - Production Pipeline

1

Frontend UI Layer

User configures momentum parameters (RSI=55, SL=5%, TP=10%) via input fields. Strategy mode is fixed to "momentum" in production.

2

Flask Route Handler (app.py)

Receives POST/GET request with target_rsi, stop_loss_pct, take_profit_pct parameters. Strategy mode is hardcoded to "momentum".

3

Scanner Generator (scanner.py)

The scan_universe_generator(strategy_mode='momentum', ...) function executes momentum-specific logic with RSI cross above 55 and price above SMA 50.

4

Trading Logic (trading_logic.py)

Processes scan results with momentum-specific entry/exit rules and position sizing calculations based on 1:2 risk/reward ratio.

5

Database Persistence (data_manager.py)

For LIVE SCANS only: Results are saved to trades_db.json with strategy metadata. DRY RUNS bypass this layer entirely.
