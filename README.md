# Stocks For Me - Quantitative Trading System

מערכת מסחר כמותי מבוססת RSI ומומנטום (Momentum Breakout) עבור מניות נאסד"ק (Nasdaq).

**אסטרטגיית הייצור (Momentum Scenario 3):** RSI חוצה מעל 55 כאשר המחיר מעל ה-SMA 50, בתנאי שמדד ה-S&P 500 מעל ה-SMA 200 שלו. Stop Loss קבוע של 5%, Take Profit קבוע של 10% (יחס סיכון/סיכוי 1:2).
תוצאות Backtest: **+567.8%** תשואה מצטברת על פני 16 שנה (2010-2026), עם Win Rate יציב של כ-43% בשני משטרי שוק שונים.

לפרטים המלאים על הארכיטקטורה, המתודולוגיה, ממצאי המחקר הכמותי, וכללי המסחר השבועיים - ראו [`project_context.md`](project_context.md).


## מבנה הפרויקט

```
stocks_for_me/
├── app.py                    # שרת Flask - נקודת כניסה ראשית
├── scanner.py                 # מנוע הסריקה השבועי
├── backtester.py              # מנוע בדיקה אחורית (week-by-week)
├── monte_carlo_backtester.py  # סימולציית Monte Carlo לזיהוי SL/TP תוך-יומי
├── trading_logic.py           # לוגיקת מסחר, כניסה/יציאה מפוזיציות
├── tracker.py                 # עדכון פורטפוליו ויצירת דשבורד
├── ui_generator.py            # יצירת ממשקי HTML (דשבורד, אנליטיקס)
├── analytics_generator.py     # חישובי ביצועים ומצב פורטפוליו
├── data_manager.py            # ניהול trades_db.json
├── currency_manager.py        # ניהול הפקדות והמרות מטבע (ILS/USD)
├── stock_api.py               # ממשק ל-Yahoo Finance
├── finance_utils.py           # פונקציות עזר פיננסיות (RSI, PnL, MWR)
├── media/                     # סרטוני הדגמה וצילומי מסך (לא ב-git)
├── cache/                     # קבצי cache לבקטסטים (*.pkl, לא ב-git)
├── output/                    # HTML שנוצר דינמית (לא ב-git)
├── trades_db.json             # מסד נתוני המסחר החי (לא ב-git)
└── deposits_history.json      # היסטוריית הפקדות
```

## הרצה מהירה (Windows)

לחיצה כפולה על הקובץ `start.bat` שבתיקיית הפרויקט. בהרצה הראשונה הסקריפט ייצור סביבה וירטואלית ויתקין את כל התלויות אוטומטית (ייקח דקה-שתיים); בהרצות הבאות זה יהיה מהיר. השרת יעלה וחלון הדפדפן יפתח אוטומטית בכתובת [http://127.0.0.1:5000](http://127.0.0.1:5000). כדי לעצור את השרת, סגור את חלון ה-CMD.

## התקנה ידנית (כל מערכת הפעלה)

```bash
pip install -r requirements.txt
```

## הרצה ידנית

```bash
python app.py
```

לאחר ההרצה, פתח את הדפדפן בכתובת: [http://127.0.0.1:5000](http://127.0.0.1:5000)
